# Product

<!-- impeccable:product-schema 1 -->

## Platform

android

## Users

People using an Android phone for everyday personal SMS/MMS. This primary audience was confirmed by the user. The repo also supports people managing high-volume inboxes through search, filters, spam controls, archive, and starred messages.

## Product Purpose

A private SMS/MMS client for reading, sending, finding, organizing, and recovering messages on the phone.

## Operating Context

Phone messaging with contacts, groups, dual SIM, notifications, media attachments, scheduled sending, and device-level default SMS permissions. Core messaging does not require network access beyond carrier transport.

## Capabilities and Constraints

Current repo capabilities include SMS/MMS, group messaging, media and contact attachments, search, archive, starred messages, spam and block rules, recycle bin, scheduled sending, per-conversation settings, message backup/restore, appearance, language, accessibility-related font sizing, and notification controls. The user explicitly allows rethinking this feature set. The design explores a new UI and product structure; it does not assume implementation changes have already been made.

## Brand Commitments

The product is named Open Line (the repo and app label are still Messages). No palette or visual system is binding for this redesign; the user explicitly authorized a new visual direction.

## Evidence on Hand

The repository's README, current activities, menus, layouts, and dialogs provide a feature inventory. Illustrative message content in the design is fictional.

## Product Principles

- Make reading and replying immediate.
- Make sender identity and message status clear.
- Make unwanted messages controllable and recoverable.
- Keep organization and settings discoverable without crowding conversations.
- Design for readable text, touch, RTL, and light/dark use.
